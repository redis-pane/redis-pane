title: "The key list"
---

The left pane is your keyspace. It fills as `redis-pane` walks the server with `SCAN`. It never
uses `KEYS`, which would block a busy server. You can move, filter and open keys while the scan
is still running, and the status bar shows its progress (`scanning 41,203 of ~180,000`).
`Esc` stops a scan that is still going. The keys already loaded stay.

## Columns

`KEY`, `TYPE`, `SIZE` and `TTL`. The type, size and TTL of a row are fetched for the rows on
screen, so a freshly scrolled row shows a placeholder for a moment and then fills in. Rows never
shift while that happens. There is no element-count column. The value pane's header states it
when you open a key.

When a row's key has been deleted or has expired, it keeps its place in the list and is
badged `✕ gone`, with its last known size. Removing it would move everything below your cursor.

## Moving

| Key | Does |
| --- | --- |
| `↑` `↓` or `j` `k` | Move the cursor. |
| `PgUp` `PgDn`, `Home` `End` | Page, jump to the top or the bottom. |
| `→` or `l` | Open the key, or expand a tree group, or step into one that is open. |
| `←` or `h` | Collapse a group, or jump to its parent. |
| `Enter` | Open the key (if needed) and put a cursor inside its value. |
| `Tab` | Move focus to the other pane without opening anything. |

The key under your cursor is the **Selected key**. The key shown in the value pane is the
**Open key**. They are often different: moving the cursor doesn't open anything, so scrolling
through a thousand keys doesn't send a thousand reads. When they differ, both panes say so. The
value pane gets a `⊘ not the selected key` badge, and the Open key's name is underlined in the
list.

## Tree and flat

`t` switches between the two views. The tree is the default.

- **Tree** groups keys on `:` (`user:8812:session` sits under `user:` then `8812:`), and
  shows how many keys each collapsed group holds. In tree view the list is in name order, and
  `s` does nothing.
- **Flat** is one row per key. `s` cycles the order: scan order, name, TTL, size, type. The
  status bar says which one is in force.

## Marking keys

`Space` marks the Selected key and moves down, so holding it marks a run. Marked rows show `◆`
(`+` in ASCII). `d` then deletes every marked key. See [Bulk delete](../editing/bulk-delete.mdx).

## Rescan

`r` in the key list walks the server again. Use it when you want keys that were created since
the scan finished. The open key doesn't need this. It is live. See
[Live updates](../viewing/live-updates.mdx).
